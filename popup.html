💡 Help & Guide

🤖 OpenAI Setup

  1. Get your OpenAI API key:
    Go to OpenAI API Keys and click Create new secret key. Copy the key (starts with sk-).
  2. Add credits and set up billing:
    Go to OpenAI Billing.
    • Add a payment method (credit card, etc.).
    • Purchase credits (required even if you finished the free trial).
    • Check your balance to ensure you have enough credits.

🌐 Google Translate Setup

  1. Create a Google Cloud Project:
    Go to Google Cloud Console and create a new project or select an existing one.
  2. Enable Google Translate API:
    Enable Google Translate API for your project.
  3. Create API Key:
    Go to Credentials and click Create Credentials → API Key.
  4. Set up billing (required):
    Set up billing for your project. Google Translate API requires billing to be enabled.

⚙️ Extension Usage

  1. Save settings individually:
    Use the individual save buttons for each service to save your settings separately.
  2. API key testing:
    The extension automatically tests your API keys with mock data to ensure they work correctly before saving.

🔧 Troubleshooting

  • OpenAI Billing/Credits Warning: Make sure you have added a payment method and purchased credits.
  • Google Translate Quota: Check your Google Cloud Console billing and quota settings.
  • Network Error: Check your internet connection and try again.
  • Authentication Error: Double-check your API keys and ensure they have the correct permissions.
